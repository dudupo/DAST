\section{Topological Sort}
Topological sort of a directed graph is a ordering of its vertices such that for every directed edge $(u,v)$ from vertex $u$ to vertex $v$, $u$ comes before $v$ in the ordering. The native application is in determining a compilation order. Imagine a huge source code, a compiler has to compile in such an order that when compiling a function, all the functions on which it depends have already been compiled.

\subsection{Depth First Search (DFS)}
As its name implies, depth-first search searches "deeper" in the graph whenever possible. Depth-first search explores edges out of the most recently discovered vertex $v$ that still has unexplored edges leaving it. Once all of $ v$'s edges have been explored, the search "backtracks" to explore edges leaving the vertex from which $v$ was discovered. This process continues until all vertices that are reachable from the original source vertex have been discovered. If any undiscovered vertices remain, then depth-first search selects one of them as a new source, repeating the search from that source. The algorithm repeats this entire process until it has discovered every vertex.


\begin{minipage}[t]{0.46\textwidth}

  \begin{algorithm}[H]
   \textbf{DFS( $G$):}\\
    \For {$v\in V$}{
 	$v$.visited $\leftarrow False$
    }
    time $ \leftarrow 1 $\\
    \For {$v\in V$}{
      \If { not $v$.visited } {
	$\pi \left( v \right)  \leftarrow $ null \\ 
	Explore( $G,v$ ) 
     } 
   }

  \end{algorithm}

  \begin{algorithm}[H]
    \textbf{Explore($G,v$):}\\
     Previsit($v$)\\
    \For {$\left( v,u \right) \in E  $}{
      \If { not $u$.visited } {
	$ \pi \left( u \right) \leftarrow v $ \\ 
	Explore( $G, u$ ) 
      }
    }
    Postvisit($v$)
  \end{algorithm}
  \end{minipage}
   \hfill
   \begin{minipage}[t]{0.46\textwidth}
  \begin{algorithm}[H]
    \textbf{Previsit($v$):}\\
    pre($v$) $\leftarrow $ time \\
    time $\leftarrow$ time $+1$
  \end{algorithm}
  \begin{algorithm}[H]
   \textbf{Postvisit($v$):} \\
    post($v$) $\leftarrow $ time \\
    time $\leftarrow$ time $+1$
  \end{algorithm}

  \end{minipage}

\paragraph{Properties of depth-first search.} Depth-first search yields valuable information about the structure of a graph. Perhaps the most basic property of depth-first search is that the predecessor subgraph $G_{\pi}$ does indeed form a forest of trees since the structure of the depth-first trees exactly mirrors the structure of recursive calls of explore-function. That is, $u$ = $\pi\left( v \right)$ if and only if explore($G, v$) was called during a search of $ u$'s adjacency list.


Additionally, vertex $v$ is a descendant of vertex $u$ in the depth-first forest if and only if $v$ is discovered during the time in which pre$(u)$ has already been set but post$(u)$ hasn't \footnote{In terms of the presentation from last week, when $u$'s color is gray}.
Another important property of depth-first search is that discovery and finish times have a parenthesis structure. If the explore procedure were to print a left parenthesis "$(u$" when it discovers vertex $u$ and to print a right parenthesis "$u)$" when it finishes $u$, then the printed expression would be well-formed in the sense that the parentheses are properly nested.

The following theorem provides another way to characterize the parenthesis structure.

\begin{theorem}[Parenthesis theorem]
In any depth-first search of a (directed or undirected) graph $G = (V, E)$, for any two vertices $u$ and $v$, exactly one of the following three conditions holds:

\begin{enumerate}
  \item the intervals [pre($u$), post($u$)] and [pre($v$), post($v$)] are entirely disjoint, and neither $u$ nor $v$ is a descendant of the other in the depth-first forest.
  \item the interval [pre($u$), post($u$)] is contained entirely within the interval [pre($v$), post($v$)], and $u$ is a descendant of $v$ in a depth-first tree, or
  \item the interval [pre($v$), post($v$)] is contained entirely within the interval [pre($u$), post($u$)], and $v$ is a descendant of $u$ in a depth-first tree.
  \end{enumerate}
\end{theorem}

%We give a proof-sketch for the 'Parenthesis theorem', the reason why is not 

Let us use the following notation: we say that line ($x$) of the recursive call 'Explore($G,v$)' is executed at time $t$ if at time $t$ the running of the algorithm got to line number $x$ of Explore where the vertex argument is $v$. Notice that since Explore is called \textbf{only once} on each vertex, the notation is well defined.
\begin{proof}
  
It's enough to prove that for any pair of vertices $v, u$, the inequality $\pre(v) < \pre(u) < \post(v)$ implies $\pre(v) < \pre(u) < \post(u) < \post(v)$. \\


Consider the call 'Explore($G,v$)'. Since the algorithm sets the value of $\post(v)$ at line number (9), and it makes all of its recursive calls between lines (3)-(8), we have that the algorithm returns from its recursive calls before time $\post(v)$. Furthermore, any line that has been executed during times $[\pre(v), \post(v)]$ is either a line of the call 'Explore($G,v$)' or a line of one of the recursive calls.\\


In particular, we have that the line which sets $\pre(u)$ is executed during times $[\pre(v), \post(v)]$, and therefore as part of a recursive call. In addition, because the recursive call was returned during the time interval, the assignment of $\post(u)$ is made before $\post(v)$. Thus, we have both $\pre(v) < \pre(u) < \post(u) < \post(v)$ and that $u$ is a descendant of $v$ in $\pi$\footnote{The algorithm defines $\pi$ to be the recursive tree}. 

\end{proof}

\begin{corollary}
  Vertex $v$ is a proper descendant of vertex $u$ in the depth-first forest for a (directed or undirected) graph $G$ if and only if pre($u$) $<$ pre($v$) $<$ post($v$) $<$ post($u$).
\end{corollary}


\section{DFS on DAGS}
We are about to come with an algorithm for sorting a DAG's vertices according to their order. The following two claims clarify the roles of $\pre$ and $\post$ in determining such order.

\begin{claim}
  \label{claim:dag}
  Let $G=(V,E)$ be a DAG, and let $v,u \in V$ such $u \leadsto v$ (There is a path from $u$ to $v$ in $G$). And let $\pi$ be a forest returned from the call \textbf{DFS$(G)$}, If $\pre(u) < \pre(v)$ then $v$ is a descendant of $u$ in $\pi$. 
\end{claim}

To prove \Cref{claim:dag}, we will define a graph $G^{\prime}$ that satisfies:
\begin{enumerate}
  \item There is only single path between $u$ to $v$ in $G^{\prime}$. 
  \item Let $\pi^{\prime}$ be the depth forest returned by the running of DFS over $G^{\prime}$, then if $v$ is a descendant of $u$ in $\pi^{\prime}$ then is also a descendant of $u$ in $\pi$. 
\end{enumerate}

\begin{definition}
Consider a graph $G$ and vertices $u, v$ such that there is a path from $u$ to $v$. Let $e_{1}, e_{2}, \ldots, e_{m}$ be the edges of the graph ordered by the access time of the DFS running over $G$. Let $G^{\prime} \subset G$ be defined by taking the minimal prefix $e_{1}, e_{2}, \ldots, e_{i}$ such that there is still a path from $u$ to $v$. Let $\pi^{\prime}$ be the forest returned by the DFS running over $G^{\prime}$, and notice that $\pi^{\prime} \subset \pi$. Observe that by minimality, there is only one path between $u$ and $v$ in $G^{\prime}$.
\end{definition}


\begin{proof}
  Consider vertices $v,u$ such $u\leadsto v$, in $G$, $\pre(u) < \pre(v)$ and $G^{\prime}$ as defined above. Assume without loss of generality that $v$ is the first of such vertex on the path that is not a descendant of $u$ in $\pi^{\prime}$. Let $v^{\prime}$ be predecessor to $v$ on that path, namely the last vertex on the '$u\leadsto v$' path before $v$.

      
  Either $\pre(v^{\prime}) < \pre(u)$ or $v^{\prime}$ is a descendant of $u$. In the first case, we get an immediate contradiction to $\pre(v) < \pre(u)$. In the second case, we consider the recursive call 'Explore($G^{\prime},v^{\prime}$)', and we have that $\pre(v) < \pre(v^{\prime})$, or otherwise the algorithm will set $\pi^{\prime}(v) \leftarrow v^{\prime}$, and hence $v$ is a descendant of $u$ in $\pi^{\prime}$.

      
So, let's focus on the case where $\pre(v) < \pre(v^{\prime})$. Let $v^{\prime \prime}$ be the predecessor of $v^\prime$. Notice that since there is a single path from $u$ to $v$, we have that $\pre(v) < \pre(v^{\prime})$ implies $\pre(v) < \pre(v^{\prime \prime})$.\footnote{That is, upon calling 'Explore($G^{\prime}, v^{\prime \prime}$)', the algorithm will first walk through paths that do not reach $v$, and then call 'Explore($G^{\prime}, v^{\prime}$)'.} Then we continue by induction until we get $\pre(v) < \pre(u)$, which is a contradiction.

\end{proof}

\begin{claim}
  \label{claim:toposort}
  Let $G=(V,E)$ be a DAG, and let $v,u \in V$ such $u \leadsto v$ (There is a path from $u$ to $v$ in $G$). Then the call \textbf{DFS$(G)$} assigns $\post(u)>\post(v)$. 
\end{claim}

\begin{proof}
Suppose, toward a contradiction, that $\post(u) < \post(v)$, and split into cases:
  \begin{itemize}
    \item Either $\pre(v) < \pre(u)$ thus, from the parenthesis theorem, $\pre(v) < \pre(u) < \post(u) < \post(v)$, and $u$ is a descendant of $v$ in $\pi$. Therefore, there is a path from $v$ to $u$ in $G$. Combining this with the given that there is a path from $u$ to $v$, there is a cycle in $G$, which contradicts $G$ being a DAG.
    \item Or, $\pre(v) > \pre(u)$, Thus, by \Cref{claim:dag}, we get that $v$ is a descendant of $u$ in $\pi$, and by combining the parenthesis theorem, we get the desired.
  \end{itemize}
\end{proof}

\Cref{claim:toposort} defines an algorithm for sorting the vertices of a DAG according to dependency, namely $v$ appears before $u$ only if there is not a directed path form $u$ to $v$, which we provide in \Cref{alg:topo}. Notice that since the $\post$ values are integers bounded by $|E|$, the sorting can be done using counting sort, and the overall running time is $O(|V| + |E|)$.

  \begin{algorithm}[h]
   $\pre, \post \leftarrow $ Call DFS($G$)\\
   \Return $G$'s vertices in $\post$-reversed ordered. 
  \caption{TopologicalSort( $G$)}
    \label{alg:topo}
  \end{algorithm}

  \section{ Strongly Connected Components }
  Denote by $G^{\top}$ the graph obtained by flipping the direction of each edge in $G$, namely, if $(u,v) \in G$, then $(v,u) \in G^{\top}$. Let's introduce the first version of an algorithm that extracts from a given graph $G$ all its strongly connected components.
  \begin{algorithm}[h]
    \For{ $v$ in $V$ }{
      $\pi \leftarrow $ Explore($G$, $v$) \\
      $ \pi^{\prime} \leftarrow$ Explore($G^\top$, $v$) \\
      print $\pi \cap \pi^{\prime}$\\
      $ V \leftarrow V / \pi \cap \pi^{\prime}$
    }
    \caption{ Find SCCs slow version.}
    \label{alg:scc_slow}
  \end{algorithm}

  \textbf{Correctness}, Denote by $C_{w}$ the subset of vertices that is printed at line (4) when the iteration is over $w$. Let $u, v$ be vertices belonging to $C_{w}$. By the correctness of Explore, line (2) guarantees that $w \leadsto u, v$, and line (3) guarantees that $u, v \leadsto w$. Therefore, we get both $u \leadsto v$ and $v \leadsto u$. To complete the proof, one also has to show that the extension $C_{w} \cup \{z\}$ for any $z \in V \setminus C_{w}$ is not strongly connected. Showing that contradicts the correctness of Explore is left as an exercise.

  \textbf{Running Time,} Denote by $T(G)$ the running time of the algorithm when called on graph $G$, and denote by $C_{1}$ the first strongly connected component that is found. Then:
   \begin{equation*}
    \begin{split}
      T(G) &= \Theta(|V| + |E|) + T(G/C_{1}) = O(|E| \cdot |V|)
    \end{split}
  \end{equation*}

  \section{SCCs in Linear Time}
Now we present \Cref{alg:scc_fast}, an algorithm to find the strongly connected components in linear time.
  \begin{algorithm}[h]
    $\pre, \ \post \leftarrow $ DFS($G^{\top}$) \\
    $V \leftarrow$ sorts $V$ in reverse order of $\post$. \\
    $ \pi \leftarrow $ DFS($G$) \\
    \Return $\pi$ 
    \caption{Find SCCs fast version.}
    \label{alg:scc_fast}
  \end{algorithm}

\begin{claim}
  \label{claim:toDag}
  Define the relation $v\sim u$ to holds if $u$ and $v$ are on the same strong connected component. Then:\begin{enumerate}
    \item $\sim$ is an equivalence relation. 
    \item Define the graph $G^{\prime}=(V^\prime, E^\prime)$ such that $V^{\prime}$ are the equivalence class respecting to $\sim$ and $\{u,v\} \in E^{\prime}$ if there is a directed path in $G$ from a vertex in $u$ into a vertex in $v$. Then $G^{\prime}$ is a DAG.  
  \end{enumerate}
\end{claim}

\begin{corollary}
  \label{corollary:DAG} 
  For $v \in V$, denote by $[v]$ the delegate of $v$ according to $\sim$. Running the topological sort on $G$ returns the vertices of $G$ according to the topological order of $G^\prime$, namely that $v$ appears before $u$ only if there is no a directed path form $[u]$ to $[v]$ in $G^{\prime}$. The proof is identical to the proof of \Cref{claim:toposort} .

  \inb{ For SCCs $C_{1}$ and $C_{2}$ such that there is a directed path from $C_{1}$ to $C_{2}$, we have that $\max_{v \in C_{1}} \post(v) \ge \max_{u \in C_{2}} \post(u)$. That result wasn't proved in the recitation. } 

\end{corollary}

\textbf{Correctness}. Denote by $C_{1}, C_{2}, C_{3}, .., C_{l}$ the strongly connected components of $G$ ordered by the topological sort of $G^{\top}$. We will prove by induction that upon the $i$th calling to 'Explore' form the second DFS call (line (3)), the algorithm scans only the vertices at $C_{i}$.

\begin{enumerate}
  \item Base. The first call to Explore is over the first vertex in the topological order of $G^{\top}$, denoted by $v$. That vertex belongs to $C_{1}$, and from it, there is a directed path to any other vertex of $C_{1}$, so it's left to show that no vertex outside $C_{1}$ is scanned on the first call. If there were $u \in C_{j}$ for $j > 1$ that was scanned, then it means that the algorithm crossed through an edge of the form $(v^{\prime}, u^{\prime})$ such that $v^{\prime} \in C_{1}$ and $u^{\prime} \in C_{j}$. But if $\left( v^{\prime}, u^{\prime} \right) \in E$, then $\left(u^{\prime}, v^{\prime} \right) \in E^{\top}$. 


    Thus, there is a directed path from $u^{\prime}$ to $v$ in $G^{\top}$. Using \Cref{corollary:DAG}, it holds that either $u^{\prime} \in C_{1}$, which contradicts $j > 1$, or that \inb{ $C_{j} \leadsto C_{1}$ and therefore $\max_{u \in C_{j}} \post(u) > \max_{v \in C_{1}} \post(v) $ (regarding $G^\top$), So the first vertex of $C_{j}$ has to appear before $v$ }, which contradicts $v$ being the first vertex in the order.
 
  \item Assumption. Assume correction for any $i^{\prime} < i$. 
  \item Step. Left as an exercise.
\end{enumerate}
