\section{Shortest Paths} 

Recall that a weighted graph $G$ is a graph equipped with a weight function $w : E \rightarrow \mathbb{R}$, where the weight of a path is defined as the sum of the weights of the edges along the path. The shortest path between two vertices is a path that connects them and is also minimal in its weight. One native application of this formulation is to model routes between destinations, where edges correspond to roads and vertices to mid-stations.

Two main algorithms are used to solve the shortest path problem. The first is Dijkstra, which is required only when the weight function is \textbf{non-negative} and runs in time $\Theta(|E| \log |V|)$ \footnote{Can be improved to $|E| + |V|\log|V|$, but that is beyond the scope of the course.}. The second is Bellman-Ford, which handles \textbf{negative} weights, yet it does so at a higher running time cost of $\Theta(|E| \cdot |V|)$.


Initially the distances from the source are initialized to $\infty$ and along the running their are decreased closer to their real value by application of relaxations. 

\section{Dijkstra}
Dijkstra can be thought of as BFS where the FIFO queue is replaced by a min-heap. Each time we extract the closest unvisited vertex, we scan its edges and check for each of its neighbors if getting to it through their edge defines a shorter path than what is currently known. If so, we update the heap. \Cref{alg:dijkstra} gives an implementation.

  \begin{algorithm}[h]
    \For { $v \in V$ }{ 
      $d[v] \leftarrow \infty $  \\
      $\pi[v] \leftarrow $ null  \\
    }
    $d[s] \leftarrow 0 $\\

    \For{ $i \in [n]$ }{
      \For { $(u,v) \in E$ } {
        \If{ $d[v] > d[u] + w(u,v)$ }{ 
          $d[v] \leftarrow d[u] + w(u,v)$ \\
          $\pi[v] \leftarrow u $ 
        }
      }
    }
    \For{ $(u,v) \in E$ }{
      \label{line:Belcon}
        \If{ $d[v] > d[u] + w(u,v)$ }{ 
          \Return Negative Cycle 
        }
    }
    \caption{Bellman–Ford.}
    \label{alg:bellman-ford}
  \end{algorithm}


  \textbf{Detecting a Negative Cycle.} Suppose that $v_{1},v_{1},\cdots v_{k}=v_{1}$ is a negative cycle. This means that: 

  \begin{equation*}
    \begin{split}
      \sum^{k}_{i=2}w(v_{i-1},v_{i}) < 0 
    \end{split}
  \end{equation*}

  Assume that the algorithm doesn't detect the cycle, namely the condition at \Cref{line:Belcon} is not satisfied for any of the edges. Then: 

  \begin{equation*}
    \begin{split}
      & \forall v_{i} \ d[v] < d[u] + w(u,v) \\
      \Rightarrow & \sum^{k}_{i=2}d[v_{i}] < \sum^{k}_{i=2}d[v_{i-1}] + \sum^{k}_{i=2}w(v_{i-1},v_{i}) \\ 
      & =  \sum^{k}_{i=2}d[v_{i}] + \sum^{k}_{i=2}w(v_{i-1},v_{i}) \\
      0 & \le \sum^{k}_{i=2}w(v_{i-1},v_{i})  
    \end{split}
  \end{equation*}
